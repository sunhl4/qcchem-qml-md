# 竞争定位与路线图

本页定义 `qchem_qml_md` 作为开放产品的竞争位置，以及分阶段工程目标。

## 竞争对象与边界

- 参考对象：Quantinuum 的公开文档与产品叙事
- 竞争焦点：编排抽象、可复现契约、可审计工程流程
- 非目标：闭源实现一比一替换、商业云与硬件能力等价

## 我们的可竞争价值

1. 全链路开源与可 fork
2. 判据与复现字段可机读导出
3. 多后端可插拔，避免单硬件绑定
4. 兼容近端与长线技术叙事（VQE 与 QPE 轨）

## 分阶段目标

### P0（短期）

- 稳定 parity/repro 导出
- 固化最小可运行配置与回归样例

### P1（中期）

- 强化嵌入与激发态路径的机读字段
- 强化缓解策略报告能力

### P2（长期）

- 完善设备级执行路径和资源估计文档
- 扩展平台化能力（多租户/配额/治理）
