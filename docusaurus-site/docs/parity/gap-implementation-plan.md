# 与 InQuanto 能力差距与实施计划

该页用于维护 `partial/no` 项的收敛计划，支撑研发排期与验收。

## 维护方式

每个差距项建议包含：

- 差距描述
- 当前状态（partial/no）
- 收敛目标
- 负责人与里程碑
- 验收标准（可机读或可复测）

## 分阶段建议

### W0

- 先闭合文档和接口契约
- 补齐示例配置与最小回归

### W1

- 闭合关键工程路径（作业、观测、参考接口）
- 对 partial 项输出可验证证据

### W2

- 扩展高价值能力（后端、缓解、估计）
- 优化性能与平台治理
