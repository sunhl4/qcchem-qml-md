本页用于记录“公开叙事可对齐能力”的覆盖状态：`yes / partial / no / n/a`。

## 覆盖标记

- `yes`：实现并可在当前工程路径验证
- `partial`：部分实现或语义相近但非同构
- `no`：未实现
- `n/a`：刻意不做或超出公开对标范围

## 当前原则

- 以开放可验证工程路径为主
- 不宣称闭源云/硬件等价
- 所有 partial 项应有后续收敛计划
