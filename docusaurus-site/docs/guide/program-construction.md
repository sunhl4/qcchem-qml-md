# P2 程序构建（Algorithms and protocols）

P2 把“化学问题”组织成“可执行程序”：算法、协议和阶段化编排在这里闭合。

## 你在 P2 主要做什么

- 算法层：VQE/ADAPT 等可插拔实现
- 协议层：可观测量计算与评估阶段
- 编排层：串联 instantiate/build/compile/run/evaluate

## 为什么这一层重要

- 这是研发扩展算法能力的主战场
- 这是稳定中间产物和调试信息的关键层
- 这是把“实验代码”变成“工程流水线”的核心边界

## 工程建议

- 算法模块与编排层解耦
- 关键中间结果结构化输出（用于复盘与回归）
- 用标准化 workflow 模板降低团队学习成本
