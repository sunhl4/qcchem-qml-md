# 工作流与 YAML 概览

本页解释一条量子化学任务在 YAML 中如何组织，帮助你从示例配置平滑过渡到自定义实验。

## 一条管线的逻辑顺序

1. 分子与经典化学（驱动、基组、电荷）  
2. 量子子问题（活性空间、映射、算法）  
3. 协议与阶段（变分、Pauli、激发）  
4. 后端与采样（statevector/qiskit/shots）  
5. 作业与可复现（HTTP、队列、repro）  

## YAML 中最常改的块

| 块 | 作用 |
|----|------|
| 分子与经典设置 | 定义体系与计算基础 |
| 量子与活性空间 | 指定映射和算法输入 |
| 后端与采样 | 执行方式、shots、提供方 |
| 作业/API | 与队列和服务接口联动 |

## 建议

- 先跑通 `configs/example_h2.yaml`
- 再按 P1-P4 逐柱扩展配置
- 通过小样例做回归，避免一次性改动过大
