# 租户与配额

:::warning 建议模式
本文描述推荐运维模式；当前开源实现以本地 FastAPI + SQLite worker 为主，租户配额/商业 IAM 未内置强制执行。
:::

该页描述平台化场景下的最小治理模型：谁能跑、能跑多少、如何保证公平。

## 推荐契约字段

| 字段 | 含义 |
|------|------|
| `workspace_label` | 逻辑租户标识 |
| `project_slug` | 项目标识 |
| `max_concurrency` | 并发上限 |
| `max_wall_time` | 单任务最长运行时间 |

## 最小治理策略（建议）

1. 每个租户默认并发上限，防止单租户占满资源
2. 超时任务自动终止并记录失败原因
3. 保留等待时长分位数，定期审查公平性

## 调度建议

- 默认 FIFO，可增加小任务穿插策略
- 对超时/重试任务设置独立队列策略
- 暴露等待时间分位数用于公平性评估
