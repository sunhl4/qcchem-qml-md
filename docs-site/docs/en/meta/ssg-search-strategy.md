# Static site generator & search (final)

## 1. Framework choice

| Option | Decision |
|--------|----------|
| **VitePress** | **In use**. Fits Markdown-first workflow, custom `theme/`, layout slots, and existing mirror tooling. |
| Docusaurus / Starlight | Not selected: migration cost; current IA is stable on VitePress. |

**Source of truth**: `docs-site/docs/**`; mother docs under `qchem_qml_md/docs/` map per [IA slug map](/en/meta/ia-mapping).

## 2. Sidebar strategy

| Area | Approach |
|------|----------|
| Product, guides, tutorials, concept, reference, parity, cloud, meta | **Curated** in `docs/.vitepress/config.ts` per locale. |
| `/mirror/**` | **`sidebar-mirror.json`** generated by `npm run scaffold:mirror` from `scripts/inquanto-tree.yaml`. |

## 3. Search

| Capability | Implementation |
|------------|----------------|
| Today | **VitePress Local Search** (`provider: "local"`), indexes Markdown at build time. |
| At scale | Optional **Algolia DocSearch** — see `docs-site/README.md`. |
| Mirror split | Host mirror on a subdomain + separate build to cap index size. |

## 4. Build & CI

- `npm run docs:build` — runs `sync:configs-table`, then VitePress build.
- `npm run verify:inquanto` — keep green before widening the manifest.
