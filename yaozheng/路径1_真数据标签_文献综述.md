## 1. 执行摘要

路径 1 是「量子数据 → 经典 ML」中最接近**传统监督学习**的一条线：量子侧扮演**昂贵 oracle**，输出能量、可观测量期望、无噪极限外推值、优化目标等；经典侧学习映射并在部署时**纯经典推理**。2024–2026 年的共识并非「量子 ML 全面优于经典」，而是：**在量子调用成本极高、且标签具有清晰物理/优化语义的场景，路径 1 已出现可工程化的 ROI**。

**已验证价值最高（TRL 4–5）的三条子线：**

| 子线 | 核心机制 | 代表性证据 |
|------|---------|-----------|
| **处理器代理（Predictive Surrogates）** | 学 \(f(\mathbf{x}) \to \langle O \rangle\)，推理零量子开销 | Nat. Commun. 2026，42 qubit 真机；测量开销降数量级 |
| **ML 量子误差缓解（ML-QEM）** | 学 \(\text{noisy} \to \text{mitigated/zero-noise}\) | NMI 2024（100 qubit）；npj QI 2025 noise-agnostic；S-ZNE 2025 |
| **VQE/QAOA 优化加速** | 学初值/能量景观/一步生成 \(\theta^\*\) | Qracle 2025；ML-VQE Optimiser 2025；Flow-VQE 2025；GPR+BO 系列 |

**化学/材料（TRL 3–4）** 以 SQD（Sample-based Quantum Diagonalization）为代表：量子输出为**可验证的基态能量/带隙**，经典后处理对角化；HfO₂/ZrO₂ 带隙与实验一致（npj Comput. Mater. 2026）。**金融/组合优化（TRL 3）** 标签为 QUBO 目标值或最优组合权重，真机 pilot 增多但 advantage 仍需谨慎表述。

**科学判断**：路径 1 的成功不依赖「量子特征空间神秘性」，而依赖 **(i) 标签可验证性 (ii) oracle 成本 >> 推理成本 (iii) 问题具有跨实例结构可迁移性**。失败模式主要是：标签来自未收敛 VQE、忽略 shot/device 漂移、无经典强基线对照。

## 2. 问题定义：何谓「真」数据

### 2.1 操作定义

称一条量子实验记录为路径 1「真」数据，当且仅当同时满足：

1. **语义锚定（Semantic anchoring）**  
   存在经典符号系统 \(\mathcal{L}\) 中的量 \(y\)，使得 \(y\) 与量子输出 \(\hat{y}\) 在明确误差度量下可比较。  
   例：基态能量 \(E_0\)（hartree）、Pauli 期望 \(\langle O \rangle\)、组合优化目标 \(C(\mathbf{x})\)、带隙 \(E_g\)（eV）。

2. **独立可验证（Independent verifiability）**  
   至少有一种**不依赖当前量子设备**的参照：精确对角化、CCSD(T)、DFT、经典 solver、实验室测量、或已收敛的高精度模拟。

3. **训练目标一致性（Target consistency）**  
   经典 ML 的 loss 直接对齐该物理/优化量，而非中间表征（如 raw bitstring 分布）。

4. **部署可经典化（Classical deployability）**  
   训练后推理阶段原则上可完全在 CPU/GPU 完成（surrogate / warm-start / mitigator）。

### 2.2 与相邻概念边界

| 情形 | 是否路径 1 | 理由 |
|------|-----------|------|
| VQE 能量 vs CCSD(T) 参照 | ✅ | 能量为经典可定义标量 |
| ZNE 外推的 zero-noise \(\langle O \rangle\) | ✅ | 标签为无噪极限期望（物理定义） |
| Pauli shadow 向量用于相分类 | ❌（路径 2） | 无逐点经典 \(y_i\) 对应 |
| 表格数据经 angle encoding 进 VQC | ⚠️ 边缘 | 输入经典；量子输出为类别概率，标签来自经典数据集 |
| AI 预测校准参数改善门 fidelity | ❌ | 标签为设备参数，非业务可观测量 |
| SQD：采样 + 经典对角化得 \(E_0\) | ✅ | 最终标签为能量/带隙 |
| Noise-agnostic QEM 用逆电路构造「伪理想」标签 | ✅（弱标签） | 训练标签可计算，非全系统精确模拟 |

### 2.3 为何路径 1 在产业上更「近」

- **ML 栈成熟**：监督回归/GNN/GPR/BO 均为工业标准。  
- **验收清晰**：MAE on energy、mitigation error、quantum call reduction 可直接汇报。  
- **NISQ 友好**：学完后可脱离量子机，规避在线噪声累积。  
- **与 benchmark 负面结论相容**：Bowles 2024、Fellner 2026 批评的是**通用小数据 QML**；路径 1 解决的是 **quantum oracle 经济学**，问题结构不同。

## 3. 形式化框架与标签分类学

### 3.1 Oracle 学习范式

设问题实例 \(z \in \mathcal{Z}\)（Hamiltonian 参数、分子几何、QUBO 矩阵），量子电路 \(U(\mathbf{x}; z)\)，测量得 noisy 估计 \(\tilde{y} = \mathcal{Q}(\mathbf{x}, z) + \epsilon_{\text{shot}} + \epsilon_{\text{device}}\)。

**路径 1 经典 ML 目标**：学习 \(f_\theta: (\mathbf{x}, z, \text{context}) \mapsto y\)，最小化

\[
\mathcal{L} = \mathbb{E}_{(\mathbf{x},z)} \left[ \ell\big( f_\theta(\cdot), y_{\text{ref}} \big) \right]
\]

其中 \(y_{\text{ref}}\) 可为：理想模拟值、外推无噪值、或实验 ground truth。

**部署收益**（当 \(C_{\text{infer}}^{\text{classical}} \ll C_{\text{query}}^{\text{quantum}}\)）：

\[
\text{ROI} \approx \frac{N_{\text{deploy}} \cdot C_{\text{query}}}{N_{\text{train}} \cdot C_{\text{query}} + C_{\text{train}}^{\text{ML}}} \quad (\text{推理阶段 } N_{\text{deploy}} \gg N_{\text{train}})
\]

### 3.2 标签类型学（Path-1 Label Taxonomy）

| 类型 | 符号示例 | 经典参照 | 典型 ML 任务 |
|------|---------|---------|-------------|
| **L1 基态/激发能量** | \(E_0, E_k\) | ED, CCSD, 实验带隙 | 回归、MLFF、SQD 后处理 |
| **L2 可观测量期望** | \(\langle O \rangle\) | 精确模拟 / 外推 | 处理器代理、QEM |
| **L3 无噪极限** | \(\langle O \rangle_{\lambda\to 0}\) | ZNE/CDR 曲线 | S-ZNE、ML-QEM |
| **L4 优化景观** | \(E(\boldsymbol{\theta})\) | 全轨迹存储 | GPR、BO、ML-VQE |
| **L5 最优参数** | \(\boldsymbol{\theta}^\*\) | 收敛 VQE 解 | Qracle、Flow-VQE |
| **L6 组合/金融目标** | \(C(\mathbf{x})\) | 经典 solver | QUBO + hybrid |
| **L7 力/梯度** | \(\mathbf{F} = -\nabla E\) | DFT/MD 参照 | 量子-经典 MLFF（新兴） |

### 3.3 标签噪声来源（必须建模）

1. **VQE 未收敛**：\(y_{\text{ref}}\) 实为局部极小 — 需 `convergence_flag`、不确定性加权。  
2. **Shot noise**：训练集方差异质 — GPR/BO 天然适配；神经网络需 heteroscedastic head。  
3. **Device drift**：校准 ID 变化导致 \(P(\tilde{y}|y,z)\) 非平稳 — 需 `device_calibration_id`、在线更新、CITL-QMEM 类迁移。  
4. **Mitigation bias**：学「已缓解」标签可能过拟合特定噪声模型 — noise-agnostic 与 augmentation 是关键进展。

## 4. 六大方法论支柱（深度综述）

### 4.1 支柱 A：量子处理器代理（Predictive Surrogates）

**科学问题**：给定固定处理器与电路族，能否用经典函数逼近 **均值映射** \(\mathbf{x} \mapsto \mathrm{Tr}[\rho(\mathbf{x}) O]\)？

**理论要点**（Liao et al., Nat. Commun. 2026）：

- **HCS（Hamiltonian-correlated surrogate）**：\(\mathbf{x}\) 强相关、可观测量随 \(\mathbf{x}\) 变化；适用于 Floquet 相、参数化 Hamiltonian 族。  
- **HQS（fixed-observable surrogate）**：\(O\) 固定、\(\mathbf{x}\) 采样自某分布；在 Pauli 噪声模型下可证 \(\epsilon\)-精度所需样本多项式可控（小范围 \(\mathbf{x}\)）。  
- 表达上采用 **截断三角-单项式展开**，与硬件非相干噪声下的解析结构对齐。

**实验规模**：

- 20 qubit 可编程超导：TFIM 族 VQE 预训练、非平衡 Floquet SPT 相识别。  
- **42 qubit**：VQE 预训练；相对「量子密集型」基线，测量开销降 **数个数量级**（报道约 0.023% 测量量仍可比或更优）。

**与相关工作的关系**：

| 工作 | 区别 |
|------|------|
| Explicit Quantum Surrogates (arXiv:2408.03000) | 针对 quantum kernel 的显式经典替身，偏理论构造 |
| Quantum kernel GPR (Quantum 2023) | 核在经典侧评估，减少 QPU 查询，规模较小 |
| 本工作 | **真机 42Q 尺度** + 数字量子模拟工作流闭环 |

**开放问题**：跨校准周期泛化、非 Pauli 噪声、动态门错误与 crosstalk 下的样本复杂度界。

---

### 4.2 支柱 B：机器学习量子误差缓解（ML-QEM）

**科学问题**：能否学习 \(g: (\text{circuit features}, \tilde{\langle O \rangle}) \mapsto \langle O \rangle_{\text{ideal}}\)，使 **运行时开销** 低于 ZNE/CDR/PEC？

#### B.1 奠基与规模化（2024）

**Machine Learning for Practical Quantum Error Mitigation**（Liao et al., *Nat. Mach. Intell.* 2024, doi:10.1038/s42256-024-00927-2）：

- 模型：线性回归、RF、MLP、GNN；特征含电路结构、噪声上下文。  
- **100 qubit** IBM 真机；深度 40 两比特门电路。  
- RF 在多种噪声剖面下 **匹配或超越 digital ZNE + twirling**，runtime 显著降低。  
- 开源：`qiskit-community/ml-qem`（数据集 + `LearningEstimator` 装饰器）。

**Adaptive NN for QEM**（*Quantum Mach. Intell.* 2024）：分类器识别错误类型 + 回归器自适应调整期望；127-qubit 实验，宣称 ~99% 精度 — 需注意与独立 test 协议对照。

#### B.2 样本效率与 ZNE 替身（2025）

**S-ZNE**（Sample-efficient QEM via classical learning surrogates, arXiv:2511.07092）：

- 用经典 surrogate 学 ZNE 外推函数 \(f(\lambda) \to f(0)\)，将多噪声级采样开销降为 **常数级**查询。  
- 标签类型 **L3**（无噪极限）。

**Improving efficiency of learning-based error mitigation**（*Quantum* 2025, q-2025-05-05-1727）：

- 针对 CDR：near-Clifford 训练电路期望聚集于 0 导致 shot 浪费。  
- 策略：构造 **期望分布更宽** 的训练电路族；LiH 基态能量验证。

#### B.3 Noise-agnostic 与弱监督（2025）

**Noise-agnostic QEM**（Liao et al., *npj Quantum Inf.* 2025, doi:10.1038/s41534-025-00960-y）：

- **无需目标过程的无噪统计**；数据增强 + NN。  
- 输入可为期望、测量统计、Wigner 函数。  
- **电路骨架迁移**：同 skeleton 新电路免重训。  
- 真机 VQE/QAOA、Ising/Kerr 动力学；优于 ZNE/CDR。

**CONNECTIONS**（ICLR 2025）：图结构编码电路；通过 **逆电路组合** 构造已知理想输出的增强电路，减弱对理想 EV 标签依赖。

**NNAS**（Physics-inspired ML for QEM, arXiv:2501.04558）：物理启发架构。

**CITL-QMEM**（Scalable measurement error mitigation via conditional independence and transfer learning, 2025）：测量错误缓解 + 迁移学习，属路径 1 标签（缓解后期望）。

#### B.4 小结：ML-QEM 设计原则

1. 特征必须编码 **电路拓扑**（GNN > 纯标量 EV）。  
2. 训练分布应覆盖 **部署电路骨架** 与噪声级。  
3. 报告 **mitigation error vs total shots vs wall-clock**，而非仅绝对误差。  
4. 与 device drift 共存需 **周期性刷新** 或 calibration-conditioned 模型。

### 4.3 支柱 C：VQE/QAOA 优化加速（学景观或学初值）

**科学问题**：减少优化循环中 **能量评估次数** \(N_{\text{eval}}\)。

#### C.1 高斯过程与贝叶斯优化

- **GPR + quantum kernel**（Imperial, 2023）：VQE 能量景观结构适配量子核；噪声仿真下少于一个数量级电路评估。  
- **GP + Implicit Filtering**（QCE 2022）：GP 作 surrogate seed，抗 shot noise。  
- **Noisy BO for VQE**（Lattice 2024）：GPR + NEI acquisition；周期核适合 Ising/lattice。  
- **EMICoRe**（2025 proceedings）：NFT + GP + BO；硬件噪声仿真下优于 SOTA；面向 lattice field theory。

#### C.2 直接预测参数

- **Qracle**（arXiv:2505.01236）：GNN 预测 VQE **初始 \(\boldsymbol{\theta}_0\)**；输入 Hamiltonian 图 + ansatz 图。  
- **ML-VQE Optimiser**（arXiv:2503.20210）：快速噪声感知优化器；学历史 \((\boldsymbol{\theta}, E)\) 轨迹。  
- **Flow-VQE**（arXiv:2507.01726）：条件 normalizing flow 学「高质量 \(\boldsymbol{\theta}\)」分布；**偏好优化** 替代高方差能量加权；可 one-shot 生成参数，将优化转为采样对话。

#### C.3 经典模拟器作 surrogate（Hessian 传递）

**Surrogate optimization of VQC**（PMC 2025）：经典近似态矢量模拟器算 **近似 Hessian**，指导 QPU 精确评估；40 qubit QPU 概念验证。与路径 1 的关系：经典模拟提供 **梯度景观标签**，量子提供 **真能量标签**。

#### C.4 RL / Shot 分配

**RL Shot Reduction**（arXiv:2405.02493）：在固定精度下减少测量 shots — 标签仍为 \(E(\boldsymbol{\theta})\)，属 **采集策略** 而非 surrogate 本体。

**设计启示**：

- 初值预测（Qracle/Flow）适合 **同族 Hamiltonian 批量** 问题。  
- GPR/BO 适合 **低维参数、昂贵噪声评估**。  
- 必须存储 **完整 VQE 轨迹**（\(\boldsymbol{\theta}_t, E_t, \text{shots}_t\)）供 ML 复用。

### 4.4 支柱 D：量子采样 + 经典后处理（SQD 范式）

**科学问题**：量子机产生 **配置样本** \(\{|\psi_i\rangle\}\) 或 bitstring，经典对角化子空间 Hamiltonian 得 **能量标签** \(E_0\)。

**工作流**（Motta et al. 系列；`qiskit-addon-sqd`）：

1. 量子：LUCJ 等 ansatz 制备并采样。  
2. 经典：**configuration recovery** + 子空间投影对角化，迭代至收敛。  
3. 输出：**L1 能量 / 带隙** — 可与实验对照。

**Periodic materials**（Duriez et al., *npj Comput. Mater.* 2026, doi:10.1038/s41524-026-02059-0）：

- Extended Hubbard lattice；HfO₂、ZrO₂；**38–46 qubit** 超导处理器。  
- 带隙与 **独立实验** 一致；优于部分 DFT/量子化学基准。  
- EHM 参数亦可作 **ML 特征**（IBM Research ACS 2025 展望）— 路径 1 向特征工程的延伸。

**与 VQE 路径 1 对比**：

| | VQE+surrogate | SQD |
|--|--------------|-----|
| 量子输出 | 期望 \(\langle H \rangle\) | 样本/bitstring |
| 经典标签 | 能量（直接） | 能量（对角化后） |
| 噪声角色 | 优化障碍 | SQD 声明对噪声样本稳健 |
| 规模瓶颈 | 优化深度 | 子空间维度 + 采样覆盖 |

### 4.5 支柱 E：化学与材料（经典参照标签）

#### E.1 纯经典大模型（路径 1 标签范式，量子非必须）

- **Hamiltonian GNN**（ICML 2025）：学电子 Hamiltonian，**3000 原子**尺度；标签为 DFT/量子化学定义的算符矩阵 — 属「经典生成路径 1 风格数据」。  
- **ResTdNN**（JCTC 2025）：跨分子/晶体尺度的 **ab initio 能量** 迁移微调。

**科学意义**：确立 **能量/力标签** 下经典 ML 的上界；量子贡献需在 **同等标签精度** 下比经典 **更省样本或更省算力**。

#### E.2 量子-经典混合

- **SQD 带隙**（见 §4.4）：当前量子化学路径 1 **最强真机证据**之一。  
- **QGNN-VQE**（EPJ D 2025）：分子排序；标签为 VQE 能量 — 注意 **标签噪声**（未收敛风险）。  
- **Q-CaDD 2026**：药物发现混合流水线；hit 活性为经典实验标签，量子为特征/排序增强。

#### E.3 迁移学习（含噪声测量）

**Transfer Learning for QML with Noisy Measurements**（Computing Conference 2025）：源域模拟标签 → 目标域有限量子数据 — 路径 1 的 **域适应** 变体。

### 4.6 支柱 F：组合优化与金融（优化目标为标签）

**标签**：QUBO/Ising 能量 \(C(\mathbf{x})\) 或最优资产配置。

- **Portfolio RBI 真机**（2025）：央行/监管场景组合优化 QUBO；真机 pilot。  
- **Financial QML Benchmark 2026**（arXiv:2601.03802）：金融预测任务上量子 **niche 增益**，非普遍优势 — 路径 1 需谨慎 claim。

**方法实质**：量子输出 **组合向量 \(\mathbf{x}\)** 及其 **目标值**；经典 ML 用于 **warm-start、实例特征→解质量预测、或 hybrid solver 调参**。

## 5. 应用领域专题

### 5.1 量子模拟与多体（能量/序参量标签）

- TFIM、Heisenberg、Hubbard **基态能量**作为标签：VQE + surrogate/QEM 为主。  
- **Floquet 相**（Predictive Surrogates 2026）：标签为序参量期望或相位边界上的 \(\langle O \rangle\)。  
- 与路径 2（shadow 相分类）分工：路径 1 适合 **已有序参量定义**；路径 2 适合 **无显式序参量**。

### 5.2 量子化学与材料科学

**证据层级**：

1. **A 级**：SQD 带隙 vs 实验（HfO₂/ZrO₂）。  
2. **B 级**：分子 VQE 能量 surrogate（中小体系，模拟+部分真机）。  
3. **C 级**：药物 hit（经典实验标签为主，量子为辅）。

### 5.3 金融与运筹

真机 QUBO 试点增多；**标签可验证**（与经典 solver 比目标值），但 **quantum advantage** 未确立。路径 1 ML 价值在 **解质量预测、热启动、风险控制下采样**。

### 5.4 边缘领域：经典输入 + 量子标签

MedMNIST-QML、卫星 NQK 等：**图像像素为经典输入**，标签为分类 ID — 严格说属 **量子增强监督学习**；量子输出（测量概率）与经典标签对应，可划入 **广义路径 1**，但量子数据非「原生输出」，本综述 **低优先级**。

## 7. Benchmark 与「优势」判据（路径 1 专用）

### 7.1 必报指标

| 指标 | 定义 |
|------|------|
| **Label error** | \(|y_{\text{pred}} - y_{\text{ref}}|\) vs 经典参照 |
| **Quantum call reduction** | \(1 - N_{\text{ML}}/N_{\text{baseline}}\) |
| **Total shot budget** | \(\sum\) shots（含训练+部署） |
| **Wall-clock ROI** | QPU-hours + CPU-hours |
| **Transfer gap** | 设备 A 训练 → 设备 B 测试 |
| **Mitigation overhead** | ML-QEM 相对 ZNE 的额外经典时间 |

### 7.2 经典强基线（路径 1 专用）

- **Surrogate**：GPR-RBF、MLP、无量子特征的物理基线。  
- **QEM**：digital ZNE、CDR、PEC **同等 shot** 对照。  
- **VQE**：SPSA、Adam、NFT **无 ML** 对照。  
- **化学**：DFT、CCSD、经典 GNN/MLFF **同标签**。

### 7.3 统计协议

- Nested CV 或 **hold-out Hamiltonian / 分子**（非随机拆参数）。  
- 报告 **标签不确定性传播**（Bayesian GP 或 bootstrap）。  
- 引用 Bowles 2024、Schnabel 2025 的 **benchmark 纪律**，即使任务为路径 1。

## 8. 成熟度、局限与未来方向

### 8.1 TRL 评估（路径 1 专属）

| 子领域 | TRL | 关键瓶颈 |
|--------|-----|---------|
| 处理器代理 | 4–5 | 校准漂移、理论界紧度 |
| ML-QEM | 4–5 | 外推电路、非马尔可夫噪声 |
| VQE 加速 | 3–4 | 高维参数景观、barren plateau |
| SQD 材料 | 3–4 | 更大单胞、采样覆盖 |
| 分子 MLFF 量子标签 | 2–3 | 力标签真机稀缺 |
| 金融 QUBO | 3 | advantage 未证 |

### 8.2 核心局限

1. **标签成本仍高**：路径 1 训练集构建依赖量子 oracle。  
2. **分布外失效**：新 ansatz、新噪声、新哈密顿量族。  
3. **与路径 2 的边界模糊**：SQD 中间为 bitstring，最终标签为能量 — **混合记录**应标 `hybrid`。  
4. **发表偏差**：正面结果多来自团队自有硬件生态。

### 8.3 2026–2028 研究方向

1. **Calibration-conditioned surrogates**：输入含校准向量，在线贝叶斯更新。  
2. **Active learning for oracle budgeting**：GPR/BO 与路径 1 天然契合。  
3. **Cross-Hamiltonian foundation → 路径 1 微调**：与路径 2 衔接（混合范式）。  
4. **Standard Path-1 Benchmark Suite**：固定 Hamiltonian 族、统一 shot 预算、多设备 test split。  
5. **力与响应性质标签**：beyond 标量能量，服务 MD/弹性。  
6. **可证样本复杂度**：何时 surrogate 需指数样本 vs 多项式（Pauli 噪声下已有初步结果）。
