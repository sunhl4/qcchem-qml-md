## 0. 核心结论

原报告提出的两条路径可以重述为：

1. **路径 1：量子设备产生可验证标签，经典 AI/ML 学习并部署。**  
   量子处理器、量子算法或量子采样流程输出能量、力、可观测量期望、无噪极限、优化目标、候选电路质量、PES/带隙等“真标签”；经典模型学习这些标签，实现 surrogate、误差缓解、优化加速、材料/化学势能面、算法发现或 solver policy。

2. **路径 2：量子设备产生原生测量表征，经典 AI/ML 用于表征学习。**  
   主要是 classical shadows、shadow model、bitstring 分布、QCBM/QGAN、生成式 quantum advantage 等，不要求每条样本都有经典逐点标签。

本报告只重点优化**路径 1**。路径 1 的科学本质不是“量子 ML 模型是否端到端打败经典模型”，而是：

> **把量子计算机看成昂贵但高价值的科学 oracle；经典 ML 的任务是最大化每一次 QPU 调用的信息价值，并把量子输出变成可复用、可迁移、可部署的经典模型。**

路径 1 未来最有前景的不是单一模型，而是一套 **quantum-oracle-efficient ML system**：量子数据采集、标签可信度分层、不确定性建模、主动学习、在线更新、跨设备迁移、强基线 benchmark 和最终经典部署。

## 1. 从原 PDF 中抽取的路径 1：重新定义与纠偏

### 1.1 原报告中路径 1 的实际范围

PDF 中路径 1 并不只是“监督学习标签”这一小类，而包括了更宽的 **quantum-generated labeled/scored data**：

- **GQE / GPT-QE / GenQAI**：AI 生成候选电路，QPU 或模拟器返回能量评分，形成“电路序列 -> 能量”的训练数据。
- **VQE-labeled machine-learning potential**：几何构型进入 VQE/量子化学流程，输出能量/力标签，训练 MLP/HDNNP/PES。
- **Microsoft–Quantinuum logical-qubit + classical shadows chemistry**：逻辑量子比特制备活性空间基态，shadow/Pauli 测量生成可估计能量和性质的经典数据，再与 AI/HPC 结合。
- **HI-VQE / SQD / active-space handover**：QPU 产生候选电子组态、CI 子空间、能量方差、波函数系数等，经典后处理得能量和 PES 标签。
- **AHS / 多体 Hamiltonian learning**：量子模拟器产生可观测量、能量或序参量标签，经典 ML 学习跨参数预测。
- **QUBO/QAOA/组合优化**：量子输出解、目标值或解分布，经典 ML 学 solver policy、warm-start 或解质量预测。

因此，路径 1 应改名为：

> **路径 1：量子 oracle 标注数据（Quantum-oracle labeled/scored data）**

比“量子输出是真数据”更准确。它允许标签来自不同可信层级：精确经典解、高精度近似、实验测量、QPU+mitigation、SQD 后处理、逻辑量子比特测量等。

### 1.2 路径 1 与路径 2 的边界

路径 1 和路径 2 的边界不取决于数据是否来自量子设备，而取决于 **ML 训练目标是否对齐一个可解释的物理/优化标签**。

| 数据形态 | 若作为训练目标 | 归类 |
|---|---|---|
| VQE 能量 \(E(R)\) | 训练 PES / MLP | 路径 1 |
| Pauli 期望 \(\langle P_j\rangle\) | 训练 QEM / surrogate | 路径 1 |
| classical shadows | 直接自监督预训练 | 路径 2 |
| classical shadows | 估计能量/性质后作为标签 | 路径 1 或 hybrid |
| bitstring samples | 学分布本身 | 路径 2 |
| bitstring samples | SQD 后对角化得到 \(E_0\) | 路径 1 / hybrid |
| QCBM/QGAN 样本 | 训练生成分布 | 路径 2 |
| QUBO 解及目标值 | 训练 solver policy | 路径 1 |

实践上建议记录为：

- `path_type = labeled`：最终训练标签是能量、期望、目标值等。
- `path_type = native`：训练目标是 shadow/bitstring 分布或自监督表征。
- `path_type = hybrid`：中间是原生测量，最终经估计器/对角化产生标签。

## 2. 路径 1 的统一数学框架

令问题实例为 \(x\)，可表示为分子几何、Hamiltonian 参数、active space、QUBO 矩阵、AHS 控制程序或候选电路上下文。令候选程序/电路/测量策略为 \(c\)。量子设备执行后返回 noisy measurement：

\[
\hat{y}_{x,c} = y_{x,c} + \epsilon_{\text{shot}} + \epsilon_{\text{device}} + \epsilon_{\text{mitigation}} + \epsilon_{\text{optimization}}.
\]

其中 \(y_{x,c}\) 可以是：

- 基态/激发态能量 \(E_0, E_k\)
- 力 \(\mathbf{F}=-\nabla_R E\)
- Pauli 期望 \(\langle P_j\rangle\)
- 无噪极限 \(\langle O\rangle_{\lambda\to 0}\)
- VQE/QAOA 能量景观 \(E(\theta)\)
- 梯度、Hessian、Fisher 信息
- QUBO/Ising 目标值 \(C(z)\)
- SQD/QSE 子空间对角化后的能量/带隙
- 候选电路质量分数或序列 reward

路径 1 训练数据可统一写成：

\[
D_Q=\{(x_i,c_i,\hat{y}_i,\hat{\sigma}_i,m_i,r_i)\}_{i=1}^N
\]

其中：

- \(x_i\)：问题实例，如几何、Hamiltonian、材料、QUBO。
- \(c_i\)：候选电路、ansatz、operator sequence、AHS schedule 或测量策略。
- \(\hat{y}_i\)：量子输出标签。
- \(\hat{\sigma}_i\)：标签不确定性。
- \(m_i\)：shots / QPU calls / wall-clock。
- \(r_i\)：reference 或 label-quality tier。

经典模型学习：

\[
g_\phi(x,c,\text{context})\approx y
\]

并通过 acquisition function 选择下一次 QPU 调用：

\[
(x_{t+1},c_{t+1}) =
\arg\max_{x,c}
\frac{I(y_{x,c};g_\phi\mid D_Q)}{\mathrm{Cost}_{QPU}(x,c)}.
\]

这就是路径 1 的核心闭环：**量子标注 -> 经典学习 -> 主动选择 -> 再量子标注**。

## 3. 路径 1 标签可信度分层

原报告中“真数据”容易被理解为完全真实、无误差。科学上应改为 **可信标签分层**。

| 层级 | 标签来源 | 可信度 | 典型用途 |
|---|---|---|---|
| Tier 0 | 精确对角化、FCI、小体系 statevector | 最高 | benchmark / 模型校准 |
| Tier 1 | CCSD(T)、DMRG、QMC、实验值、高精度经典近似 | 高 | 化学/材料主参考 |
| Tier 2 | QPU + mitigation、logical qubit、SQD/QSE、跨设备一致结果 | 中高 | quantum utility 目标 |
| Tier 3 | noisy VQE、未收敛优化、单设备单次实验 | 低 | 探索/主动学习，不宜作强 claim |

路径 1 报告必须存储：

```yaml
label_quality:
  tier: "Tier0 | Tier1 | Tier2 | Tier3"
  reference_method: "FCI | CCSD(T) | DMRG | experiment | QPU+QEM | SQD"
  convergence_flag: true
  mitigation_bias_estimate: optional
uncertainty:
  statistical_std: ...
  systematic_std: ...
  confidence_level: 0.95
  source: "shot_bootstrap | jackknife | bayesian_gp | mitigation_ensemble"
```

这比单纯说“真数据”更适合科学发表和工程复现。

## 4. 方法支柱 A：GQE / GPT-QE / GenQAI 与 AI 驱动电路发现

### 4.1 科学定位

GQE（Generative Quantum Eigensolver）将量子算法设计转化为**序列生成问题**。给定 operator pool，模型生成电路 token 序列：

\[
U(j_{1:N}) = U_{j_N}\cdots U_{j_1},
\quad
E(j_{1:N}) = \mathrm{Tr}[H U(j_{1:N})\rho_0 U^\dagger(j_{1:N})].
\]

量子设备或模拟器提供序列能量 \(E\)，经典 GPT/Transformer 学习“哪些序列会产生低能量状态”。这属于路径 1，因为模型训练信号是明确可验证的能量或目标值。

### 4.2 代表文献

**Nakaji et al. 2024, GQE/GPT-QE**  
提出 transformer-based GPT-QE，用类似语言模型的方式生成量子电路。演示体系包括 H2、LiH、BeH2、N2。其贡献不在于直接证明量子优势，而在于提出了“电路序列 -> 能量标签 -> 生成模型优化”的新型路径 1 数据循环。

**Quantinuum GenQAI / NVIDIA CUDA-Q / InQuanto Nexus**  
产业侧将 GQE 扩展为 AI proposal generator + quantum evaluator + HPC/QPU backend 的工作流。其潜在价值是把 QPU 从“每一步优化器”变成“高价值候选程序评分器”。

**Finger et al. 2026 automated algorithm discovery**  
使用 AI 发现近端量子算法/ansatz，在 LiH、H2O、F2 等分子 ground-state search 中降低 operator sequence 和 two-qubit gate 资源。这是 GQE 思路向 ADAPT-VQE / QEB-ADAPT-VQE 的算法发现延伸。

**Conditional-GQE 2025**  
把 GQE 推向组合优化：模型条件化于问题实例，输出候选电路或解策略。这里标签是优化目标或解质量。

### 4.3 应如何写入优化报告

原 PDF 对 GQE 的表述偏产业和案例驱动，建议改成三层：

1. **数据层**：\((\text{token sequence}, E, shots, backend, mitigation)\)
2. **模型层**：Transformer / GBDT / GNN / flow model / policy model
3. **闭环层**：proposal -> quantum scoring -> replay buffer -> policy update

关键 KPI：

- 达到 chemical accuracy 所需 QPU evaluations
- top-k generated circuits 中低能量占比
- two-qubit gate count / depth reduction
- 相比 ADAPT-VQE、UCCSD、QAOA、classical search 的资源优势
- 跨分子、跨 bond length、跨 active space 泛化

## 5. 方法支柱 B：VQE 标注机器学习势能面与 MLFF

### 5.1 科学定位

这是原 PDF 第一条路径中最清晰的“量子真标签 -> 经典模型部署”范式：

\[
R_i \mapsto H(R_i) \mapsto \hat{E}_i,\hat{F}_i \mapsto E_\phi(R),F_\phi(R).
\]

量子设备不直接跑长时间 MD，而是提供少量电子结构标签；经典 MLP/HDNNP/MLFF 学习势能面后，执行长期稳定分子动力学。

### 5.2 代表工作：Schuhmacher et al. 2022

**Extending the Reach of Quantum Computing for Materials Science with Machine Learning Potentials**（AIP Advances 2022）是路径 1 的奠基工作之一。

关键点：

- 讨论了三类量子标签噪声：统计噪声、优化误差、硬件误差。
- 证明只要噪声低于一定阈值，MLP 可学到平滑 PES。
- 构建了首个来自 IBM Quantum 真实处理器电子结构数据的 MLP（H2 体系）。
- 其核心思想是：量子计算不直接替代 MD，而是提供高价值标签来训练经典势函数。

该工作应作为路径 1 化学材料方向的基础引用，而不是只作为案例。

### 5.3 与传统 MLFF 的关系

路径 1 在化学材料上的严谨 benchmark 必须与经典 MLFF 对照：

- DFT-labeled MLP / HDNNP / NequIP / MACE / BIGDML
- CCSD(T)-labeled small molecule force field
- Δ-learning：量子标签只学习 DFT bias 修正
- multi-fidelity：大量 DFT + 少量 QPU/SQD/CCSD(T) 标签

近期更合理的方向不是“QPU 标签完全替代 DFT”，而是：

> QPU/SQD/logical-qubit 标签用于强关联小 active space 或 DFT 失效区域，经典 MLFF 负责全空间部署。

## 6. 方法支柱 C：Logical-qubit / classical-shadow chemistry workflow

### 6.1 原 PDF 的核心案例

原 PDF 提到 Microsoft–Quantinuum 2024 workflow：HPC + AI + reliable/logical quantum computing + classical shadows，用于催化体系 active space 的 ground-state energy 估计。

这条线不是纯路径 2，因为最终训练/估计目标仍是化学性质和能量；但它使用 classical shadows 作为中间数据，因此应标为 **hybrid leaning to Path 1**。

### 6.2 代表文献

**van Dam et al. 2024, End-to-End Quantum Simulation of a Chemical System**

核心流程：

1. AutoRXN/AutoCAS/HPC 找到反应网络和强关联 active space。
2. Quantinuum trapped-ion hardware + Microsoft qubit virtualization 制备逻辑量子比特态。
3. 对逻辑量子比特进行随机 Pauli/classical-shadow 测量。
4. Classical estimator / AI 从 shadow 数据估计 active-space ground-state energy 与其他 observables。
5. 与 physical qubits 和 classical reference 对照。

### 6.3 科学意义

它的意义不是“shadow 本身就是路径 1”，而是证明了：

> 未来化学 quantum utility 不会是孤立 QPU 任务，而是 HPC active-space screening + logical quantum state preparation + shadow/observable estimation + AI surrogate 的端到端 workflow。

### 6.4 局限

- active space 很小，不能直接外推到大规模化学。
- 许多环节由经典 HPC 和 AI 完成，不能把最终结果全部归因于 QPU。
- chemical accuracy claim 需要说明 active-space truncation、logical encoding、measurement budget 和 classical reference。

建议报告中使用表述：

> 这是路径 1 的高可信 proof-of-concept，展示“量子测量数据可转化为化学标签并被经典 AI 消费”，但不是通用量子化学优势的最终证明。

## 7. 方法支柱 D：HI-VQE、SQD 与 handover active-space workflow

### 7.1 HI-VQE 的位置

HI-VQE / handover iterative VQE 的思想是：让 classical method、QPU sampling、configuration recovery、subspace expansion 交替工作，把 QPU 输出转化为更可靠的能量、方差和波函数子空间标签。

典型标签包括：

- ground-state energy
- energy variance
- CI coefficients
- selected determinants/configurations
- PES points
- strong-correlation diagnostics

### 7.2 代表文献

- Pellow-Jarman et al. 2025：HIVQE 框架。
- Yoo et al. 2026：扩展到 N2、Fe-S cluster 等强关联体系。
- Qunova/IBM Qiskit Function：把 HI-VQE 做成 chemistry function-as-a-service。
- SQD periodic materials：HfO2/ZrO2 带隙，38–46 qubit，最终输出能量/带隙标签。

### 7.3 与路径 2 的关系

HI-VQE/SQD 中间会产生 bitstrings 和样本分布，但最终任务是能量、带隙、PES 等可解释标签。因此它应归入：

> **路径 1 / hybrid：原生测量作为中间表示，经典后处理产生路径 1 标签。**

### 7.4 未来价值

比普通 VQE 更有前途，因为它避免了“单一 variational loop 对噪声极敏感”的问题，转而利用：

- sample recovery
- 子空间对角化
- classical selected CI / HCI
- active learning PES sampling
- ML surrogate for configuration selection

## 8. 方法支柱 E：Predictive Surrogates 与 processor emulation

### 8.1 为什么应加入原报告

原 PDF 的路径 A 已经有“surrogate / QPU labeler / acquisition”思想，但没有充分纳入 2025/2026 predictive surrogates 的理论和真机证据。

**Demonstration of efficient predictive surrogates for large-scale quantum processors**（Nat. Commun. 2026）应成为路径 1 的核心文献。

### 8.2 科学内容

该工作学习：

\[
f(x) = \mathrm{Tr}(\rho(x)O)
\]

即量子处理器对给定参数和观测量的 mean-value behavior。

两类 surrogate：

- HCS：Hamiltonian-correlated surrogate
- HQS：fixed-observable surrogate

实验涉及 20/42 qubit 超导处理器，用于 VQE 预训练和 Floquet SPT phase identification，并显著降低 measurement overhead。

### 8.3 与 GQE/VQE/MLP 的关系

Predictive surrogate 是路径 1 的通用基础件：

- GQE 中可作为 energy scorer 的近似器。
- VQE 中可作为 optimizer 的低成本 oracle。
- QEM 中可作为 noisy-to-clean mapper 的一部分。
- AHS/Hamiltonian learning 中可作为 observable predictor。

## 9. 方法支柱 F：ML-QEM 与 benchmark 化

### 9.1 原 PDF 缺口

原 PDF 更关注 GQE、shadow、VQE、AHS、QGAN；但路径 1 若要科学全面，必须把 **ML-QEM** 放入核心。因为 ML-QEM 是目前最接近工程实用的路径 1 应用之一。

### 9.2 代表工作

**Liao et al. 2024, Machine learning for practical quantum error mitigation**  
100-qubit IBM hardware，RF/MLP/GNN 学 noisy -> mitigated expectation，降低 ZNE runtime overhead。

**Noise-agnostic QEM 2025**  
通过数据增强和 neural model 减少对理想无噪标签的依赖，可用于 VQE/QAOA、many-body dynamics、CV systems。

**QEM-Bench / QEMFormer 2025**  
ICML 2025，22 个数据集，统一 benchmark 学习型 QEM，并提出多尺度 circuit encoder。

### 9.3 路径 1 启示

ML-QEM 将路径 1 从“学最终能量”扩展为：

- 学 noisy expectation -> clean expectation
- 学 circuit/noise context -> mitigation correction
- 学 calibration drift -> model update
- 学 optimal measurement allocation

未来它会从离线后处理变成实时闭环：

```text
calibration stream
 -> noise-aware model
 -> shot allocation / circuit choice
 -> QPU run
 -> mitigated observable
 -> model update
```

## 10. 方法支柱 G：VQE/QAOA 优化、在线学习与梯度标签

### 10.1 为什么是路径 1

VQE/QAOA 优化中，每一次 QPU 评估都产生路径 1 标签：

\[
(\theta, H, ansatz, backend) \mapsto \hat{E}(\theta)
\]

这些轨迹如果被保存，就是极有价值的监督数据。

### 10.2 关键路线

- GPR / Bayesian optimization：低维、昂贵、noisy objective。
- Qracle：GNN 预测初始参数。
- Flow-VQE：normalizing flow 生成高质量初值。
- ML-VQE optimizer：学历史轨迹。
- Online quantum circuit learning：无预训练，边测边学。
- Bayesian Parameter Shift Rule / GradCoRe：复用历史观测估计梯度，并按不确定性自适应分配 shots。
- Surrogate Hessian VQC：经典近似模拟器提供 Hessian，QPU 提供真实能量。

### 10.3 关键纠偏

不能只保存最终收敛能量。必须保存：

```yaml
vqe_trace:
  - theta:
    energy:
    energy_std:
    gradient:
    gradient_std:
    shots:
    optimizer:
    step:
    accepted:
    backend:
    calibration_id:
```

否则无法训练下一代 optimizer/surrogate。

## 12. QCBM/QGAN 在路径 1 中的正确位置

原 PDF 把 QCBM/QGAN 放进生成量子数据大图中，这是合理的；但若本报告聚焦路径 1，需要更谨慎。

QCBM/QGAN 多数情况下属于路径 2：学习 quantum-generated distribution。但在以下情况下可转入路径 1：

- 生成样本被某个可验证目标函数评分，例如材料结构稳定性、QUBO cost、风险函数。
- QGAN 作为 classical generator 的 latent prior，最终 benchmark 是 MMD/KS/FID/目标 property。
- QPU 生成的候选样本用于训练 classical surrogate 或 solver policy。

因此建议报告中把 QCBM/QGAN 作为 **附属/交叉方向**，而非路径 1 主干。

## 14. Benchmark 协议：路径 1 必须怎么评估

### 14.1 必报指标

| 指标 | 含义 |
|---|---|
| Label MAE/RMSE | 预测标签与 reference 的误差 |
| Quantum call reduction | 相比无 ML baseline 减少多少 QPU calls |
| Total shot budget | 训练、验证、部署总 shots |
| QPU-hours / queue time | 实际 wall-clock 成本 |
| Transfer gap | 跨分子、Hamiltonian、设备、calibration 的性能下降 |
| Uncertainty calibration | 预测置信区间是否可靠 |
| Baseline parity | 同 shot / 同 wall-clock 下是否优于经典和非 ML 量子方法 |

### 14.2 分方向基线

- GQE/GPT-QE：ADAPT-VQE、UCCSD、random search、beam search、classical evolutionary search。
- VQE optimizer：SPSA、COBYLA、NFT、Adam、Bayesian optimization baseline。
- MLP/PES：DFT-labeled MLP、CCSD(T)-labeled small data、NequIP/MACE/BIGDML。
- ML-QEM：ZNE、CDR、PEC、readout-only mitigation。
- SQD/HI-VQE：selected CI、HCI、DMRG、classical diagonalization。
- QUBO/QAOA：Gurobi/CP-SAT/local search/simulated annealing。

### 14.3 数据拆分原则

随机拆分通常过于乐观。路径 1 应使用：

- hold-out molecule
- hold-out bond-length region
- hold-out Hamiltonian family
- hold-out ansatz
- hold-out backend
- hold-out calibration window
- time-based split

## 16. 路径 1 未来发展路线

### 16.1 2026–2027：从案例展示到 benchmark 化

近期最重要的是标准化：

- QEM-Bench 类 benchmark 扩展到 surrogate、VQE optimizer、GQE。
- 统一 shot budget、设备 metadata、calibration split。
- 论文必须报告 classical baseline 与 quantum baseline。
- “quantum advantage” 改成更可审计的 “QPU-call efficiency / label efficiency / wall-clock efficiency”。

### 16.2 2027–2028：在线主动学习成为主流

离线先采数据再训练不适合 QPU 稀缺场景。路径 1 将走向：

```text
historical data / simulator prior
 -> uncertainty-aware surrogate
 -> acquisition chooses next QPU job
 -> QPU returns label + uncertainty
 -> model updates
 -> stop when target confidence reached
```

核心研究问题：

- acquisition 如何同时考虑 shots、queue time、two-qubit gate cost？
- 如何在 noisy / drifting device 下保持 uncertainty calibrated？
- 如何跨 backend 重用旧数据？

### 16.3 2028–2030：跨任务 foundation encoder

未来会出现三类基础模型：

1. **Circuit foundation encoder**  
   输入 circuit DAG、observable、noise context，输出用于 QEM/surrogate 的通用表示。

2. **Hamiltonian-family surrogate**  
   输入 Hamiltonian 图、active space、ansatz token，输出能量/期望/gradient。

3. **Device-conditioned oracle model**  
   输入 calibration vector、backend topology、pulse/gate metadata，预测 noisy-to-clean correction。

这些模型会与路径 2 的 shadow/bitstring 预训练合流：路径 2 提供大规模无标签表征，路径 1 提供稀疏高质量标签微调。

### 16.4 化学材料：从能量到力、响应和反应网络

最有产业价值的路径 1 不只是 \(E_0\)，而是：

- forces
- Hessian / phonon
- dipole / polarizability
- excitation energy
- reaction barriers
- nonadiabatic couplings
- active-space correction to DFT

短期最现实路线：

> 大量 DFT 标签 + 少量 QPU/SQD/logical-qubit 高价值标签，用 multi-fidelity ML 修正强关联区域和反应关键点。

### 16.5 QEM：从后处理到实时测量控制

ML-QEM 会从：

```text
noisy expectation -> clean expectation
```

演化为：

```text
calibration -> choose circuits/shots/observables -> QPU run -> clean estimate -> update model
```

这意味着路径 1 的模型不只是 predictor，也是实验策略控制器。

### 16.6 GQE / algorithm discovery：从 token search 到 scientific agent

GQE 会从“生成电路序列”扩展为：

- active-space 选择
- ansatz/operator pool 选择
- measurement grouping 选择
- backend-aware compilation
- QPU budget-aware search
- chemical target-conditioned circuit generation

最终形态是 scientific agent：提出候选 quantum workflow，让 QPU/HPC 评估，吸收标签并迭代。

## 19. 最终判断

路径 1 是近期最值得认真投入的量子数据方向，因为它不依赖“通用量子机器学习优于经典”这一高风险命题，而依赖更可审计的工程事实：

1. QPU 调用很贵。
2. QPU 输出某些物理/优化标签具有高价值。
3. 经典 ML 很擅长从少量昂贵标签中学习 surrogate、误差修正器和策略模型。
4. 如果能标准化记录不确定性、设备上下文和 baseline，就能形成可复用的数据资产。

因此，路径 1 的未来不是单点模型，而是一个闭环：

```text
Quantum oracle
 -> labeled/scored data with uncertainty
 -> classical surrogate / QEM / optimizer / MLFF
 -> active acquisition
 -> fewer and better QPU calls
 -> classical deployment in chemistry, materials, many-body, optimization
```

这也是原报告第一条路径应强化的主线。
