# Classical chemistry & embedding

**CI classical paths:** default PR/nightly numerical chemistry uses **`scf.driver=pyscf`** (matrix `test` job + representative YAMLs). **Psi4** cross-backend parity runs in the separate **`test-psi4`** CI job (`pytest -m psi4` + `configs/example_h2_psi4_rhf_sto3g.yaml` E2E). **Precomputed-only** ingress is exercised on Python 3.12 via `scripts/smoke_pipeline.py --precomputed-only` (no PySCF import required).
