![H₂ UCCSD 变分电路](figures/pipeline/h2_uccsd_circuits.png)

#### 图注：每一个符号与操作的含义

**总标题与副标题**

| 文字 | 含义 |
|------|------|
| H₂ UCCSD–VQE Circuit (Jordan–Wigner) | 算法名：用 **UCCSD** 作变分 ansatz，用 **VQE** 优化能量；费米子→量子比特映射为 **Jordan–Wigner (JW)** |
| sto-3g | 原子基组 |
| H–H = 1.4 Bohr | 固定核间距（与 `example_h2_uccsd.yaml` 一致） |
| 4 qubits | 活性空间 2 轨道 × 2 自旋 = 4 个自旋轨道 → 4 根量子比特线 |
| 5 variational parameters \(\theta\) | 簇算符参数：\(T_1\) 有 4 个角 \(\theta_0,\theta_1,\theta_2,\theta_3\)，\(T_2\) 有 1 个角 \(\theta_4\) |

**左侧标注**

| 符号 | 含义 |
|------|------|
| 大括号 + Qubits \(q_0\)–\(q_3\) | 四根水平线 = 四比特；编号从上到下 \(q_0,q_1,q_2,q_3\) |
| (JW spin-orbitals) | 每根线对应一个 JW 自旋轨道（不是空间坐标） |
| Same 4 qubits（下半图） | 硬件展开仍作用在同一套 4 比特上 |

**阶段 (1) Prepare \(|\mathrm{HF}\rangle\)**

| 符号/操作 | 含义 |
|-----------|------|
| 水平细线 | 量子比特时间线，从左到右演化 |
| 方框内 \(X\) | Pauli-\(X\)（NOT）门：\(\lvert0\rangle\to\lvert1\rangle\) |
| 仅 \(q_2,q_3\) 上有 \(X\) | 把两电子放入占据自旋轨道 |
| \(\lvert1100\rangle\) | 态矢量写法 \(\lvert q_3 q_2 q_1 q_0\rangle=\lvert1100\rangle\)，即本例 HF 参考态（实跑比特串） |
| 竖直虚线 | 阶段分隔（参考态制备结束） |

**阶段 (2) Singles \(U_{T_1}\)**

| 符号 | 含义 |
|------|------|
| 圆角实线大框 \(U_{T_1}\) | 单激发簇酉算符整块（抽象层，不画内部门） |
| \(e^{T_1-T_1^\dagger}\) | 数学定义：反厄米生成元 \(T_1-T_1^\dagger\) 的指数映射，保证酉性 |
| \(\theta_{0:3}\) (4×2 Pauli) | 4 个变分角；每个单激发展开为 **2** 条 Pauli 旋转乘积（本 run：`XZYI,YZXI` / `XZZY,YZZX` / `IXYI,IYXI` / `IXZY,IYZX`） |

**阶段 (3) Doubles \(U_{T_2}\)**

| 符号 | 含义 |
|------|------|
| 加粗边框大框 \(U_{T_2}\) | 双激发簇酉算符（图中加粗以强调化学相关能主要来自 \(T_2\)） |
| \(e^{T_2-T_2^\dagger}\) | 双激发反厄米指数 |
| \(\theta_4=-3.029\) (8 Pauli) | 实跑优化得到的双激发角；展开为 **8** 条 Pauli（`XXXY,XXYX,XYXX,XYYY,YXXX,YXYY,YYXY,YYYX`） |

**阶段 (4) Estimate \(\langle H\rangle\)**

| 符号/操作 | 含义 |
|-----------|------|
| 表盘方框 | **测量**符号（读出） |
| \(\langle H\rangle\) | 求分子哈密顿量期望值（目标能量） |
| \(=\sum_k c_k\langle P_k\rangle\) | \(H=\sum_k c_k P_k\)（Pauli 分解）；对每条 Pauli 串测期望再加权求和 |
| 虚线框 Classical VQE | **经典**优化器：根据 \(E(\theta)\) 更新 \(\theta\)（量子端不负责优化） |
| minimize \(E(\theta)\) / update \(\theta\) | VQE 外环：最小化能量 → 把新 \(\theta\) 送回 (2)(3) |

**中间公式行**

| 式子 | 含义 |
|------|------|
| \(\lvert\psi(\theta)\rangle=e^{T_1-T_1^\dagger}\,e^{T_2-T_2^\dagger}\,\lvert\mathrm{HF}\rangle\) | 完整 ansatz：先单激发、再双激发，作用在 HF 上 |
| \(E(\theta)=\langle\psi(\theta)\lvert H\rvert\psi(\theta)\rangle\) | VQE 损失函数 = 该态上的哈密顿期望 |

**阶段 (5) 硬件展开 \(R_{XXXY}(\phi)\)**（把 \(U_{T_2}\) 里**一条** Pauli 旋转拆成元门）

| 符号/操作 | 含义 |
|-----------|------|
| \(R_{XXXY}(\phi)=\exp(-i\phi\,XXXY/2)\) | 对 Pauli 串 \(P=X\otimes X\otimes X\otimes Y\) 做旋转；\(\phi\) 由 \(\theta_4\) 与 Pauli 系数决定 |
| \(\sqrt{X}\)（即 SX） | \(Y\) 基变换的一部分（本管线对 \(Y\) 用 \(\sqrt{X}\)，对 \(X\) 用 \(H\)） |
| \(H\) | Hadamard：把 \(X\) 本征基转到 \(Z\) 计算基，便于用 \(R_Z\) 实现 |
| 实心点 + 圆圈加号，竖线相连 | **CNOT / CX**：点=控制比特，⊕=目标比特；梯形把多比特 Pauli 奇偶性收集到一根线上 |
| \(R_Z(0.757)\) | 绕 \(Z\) 轴旋转，角度 \(\phi\approx0.757\)（实跑 `XXXY` 项）；整条旋转的唯一参数门 |
| \(\sqrt{X}^\dagger\)（SX†） | \(\sqrt{X}\) 的逆，与右侧 \(H\) 一起**逆序还原**基变换 |
| 右半段 CX / \(H\) / SX† 与左半对称 | 先变换→CNOT 收集→\(R_Z\)→CNOT 还原→基还原，实现 \(\exp(-i\phi P/2)\) |

**页脚数字**

| 文字 | 含义 |
|------|------|
| Full prep = 192 elementary gates | 整条 UCCSD 制备电路元门总数（所有 Pauli 都按 (5) 展开后） |
| CX=80, \(H\)=48, \(\sqrt{X}/\sqrt{X}^\dagger\)=24/24, \(R_Z\)=16 | 各类门计数（与 live CircuitIR 一致） |
| Verified run: \(E_{\mathrm{SCF}},E_{\mathrm{var}},E_{\mathrm{FCI}},\lvert\Delta\rvert\) | 同几何能量核对：变分能量对齐 FCI（\(\sim10^{-9}\) Ha） |
| Time / algorithm flow | 横轴方向 = 时间 / 算法流程从左到右 |

**一句话串起来：** 先用 \(X\) 制 HF → 用 \(\theta\) 参数化的 \(U_{T_1}U_{T_2}\) 造 \(\lvert\psi\rangle\) → 测 \(\langle H\rangle\) → 经典更新 \(\theta\)；每个 \(T_k\) 块内部都是若干条像 (5) 这样的 Pauli 旋转元电路。

### 4.3 在线学习实测：H₂ 全 PES 覆盖训练 → 力场驱动 MD（job 8992）

#### 问题与思路

经典 ML 力场（NEP / MACE / NequIP）的第一原则：**训练集必须覆盖 MD 会遇到的全部构型空间**。H₂ 的构型空间从强压缩（~0.5 Bohr）到解离渐近区（~cutoff），若种子扫描只覆盖平衡附近，模型在未覆盖区只能外推 → 力场失准 → MD 飞散 → 死循环。

本 run 按「**非零样本三阶段**」在 HPC 执行（job **8992** · `compute01` · 30 核/120G · 限时 15h · statevector VQE），核心改进是**种子扫描覆盖 [0.5, 10.5] Bohr 全 in-cutoff PES**。

#### 三阶段配置

| 阶段 | 内容 | 本 run |
|------|------|--------|
| **A** | 量子化学键长扫描建集 | **40 点**（0.5–10.5 Bohr）→ **41** 帧（bound 11 + dissociating 30） |
| **B** | 仅在扫描集上预训练 | 150 epoch · E-MAE **1.84 Ha** · F-RMSE **3.60** · `subtract_mean` |
| **C** | warm-start 后在线学习 | **12 轮计划**（完成 9 轮，15h 截断）· 30 ep/轮 · 8q/3L 模型 |

配置：`configs/example_h2_qmlff_bondscan_ol_p3.yaml` · 数据：`results/h2_bondscan_ol_statevector_r12_8992/`

#### 全 PES 能量曲线：FCI vs QML-FF

![FCI vs QML-FF 全 PES 对比](figures/uqc/h2_bondscan_ol_8992_pes_comparison.png)

上图展示 59 个训练帧（覆盖 [0.5, 10.5] Bohr 全范围）的 **FCI 精确解**（PySCF/STO-3G）与 QML-FF 预测对比，并标注 VQE 未收敛帧：

- **左**（E-R 曲线）：FCI（蓝）呈现经典 H₂ 势能面——压缩区 −0.41 Ha → 平衡井 −1.137 Ha（~1.4 Bohr）→ 解离渐近线 −0.933 Ha；QML-FF（红 ×）在平衡区贴合良好；橙色三角形为 VQE 未收敛帧（误差 0.02–0.83 Ha），集中在压缩区（R < 1.0）和拉伸区（1.5–3.0 Bohr）
- **右**（全范围 parity）：训练帧 vs FCI 的 MAE = 0.048 Ha，max\|Δ\| = 0.555 Ha；平衡区点接近 y=x 对角线

> **VQE 数据质量问题**：在线学习用 VQE（HEA depth=1 + COBYLA）生成训练标签，在压缩区和拉伸区（键断裂强关联）8/59 帧 VQE 未收敛到基态、误差 0.02–0.83 Ha。用 FCI 精确解重新评估后，QML-FF 实际 MAE 从 0.100 Ha 降至 0.048 Ha——**模型比 VQE 数据显示的更好**，大误差主要来自错误的训练标签而非模型能力不足。修复方向：换 UCCSD ansatz 或增大 HEA depth + warm-start 初始化。

#### FCI 精确解微调：修正 VQE 标签误差

既然 VQE 标签在压缩/拉伸区存在系统性误差，下一步自然是**用 FCI 精确解替换训练标签、在已有 checkpoint 基础上继续训练**（warm-start fine-tune，非在线学习）。对 59 个训练帧用 PySCF/STO-3G 计算 FCI 能量+解析核力梯度（CASCI(2,2) = H₂/STO-3G 的 FCI），替换原始 VQE 标签后以 lr=1e-3、force_weight=10、100 epochs 继续训练：

![FCI 微调总览：训练曲线·PES 对比·parity](figures/uqc/h2_bondscan_ol_8992_fci_finetune_overview.png)

**怎么读三联图：**

- **左**（训练曲线）：total loss 在 100 epochs 内从 1581 降至 1576（force loss 主导）；E-MAE 从 0.47 eV 稳定降至 0.20 eV；F-RMSE 从 2.67 缓慢降至 2.34 eV/Å
- **中**（PES 对比）：FCI（黑实线）呈现经典 Morse 势——压缩区 −0.41 Ha → 平衡井 −1.137 Ha（~1.4 Bohr）→ 解离渐近线 −0.933 Ha；**QML-FF 微调后（红虚线）在全范围贴合 FCI**，仅在 R < 1.0 Bohr 强压缩区有偏离；VQE 原始数据（蓝虚线）的噪声/未收敛清晰可见
- **右**（parity）：59 个训练帧 QML 预测 vs FCI，**整体 MAE = 0.015 Ha = 0.41 eV**；大部分点紧贴 y=x 对角线，仅压缩区 2 个离群点（FCI 能量极高、模型欠拟合）

**分区域精度（微调后）：**

| 键长区间 | MAE (Ha) | MAE (eV) | 评价 |
|----------|----------|----------|------|
| R < 1.0 Bohr（强压缩） | 0.247 | 6.7 | 差——FCI 曲线极陡，模型欠拟合 |
| 1.0–1.5 Bohr（平衡） | **0.0017** | **0.046** | **化学精度以内** |
| 1.5–3.0 Bohr（拉伸） | **0.0033** | **0.091** | 优秀 |
| > 3.0 Bohr（解离） | **0.0029** | **0.078** | 优秀 |

- **平衡+拉伸+解离区 MAE < 0.004 Ha**（~0.1 eV），达到化学精度量级
- **压缩区仍差**：FCI 在 R < 0.8 Bohr 能量从 −0.91 飙升到 −0.41 Ha，梯度极陡，当前 8q/3L 模型容量不足以拟合；需更深 ansatz 或该区域加密训练
- **对比 VQE 原始训练**：微调后平衡区 MAE 从 0.048 Ha 降至 0.0017 Ha（**改善 28 倍**），证明 VQE 标签误差是主要瓶颈
