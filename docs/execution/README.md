# Execution engineering docs

This directory holds **active engineering checklists, design notes, and the comparative backlog**.

- **Canonical backlog:** [`comparative_execution_backlog.yaml`](comparative_execution_backlog.yaml) — validated in CI via `scripts/check_comparative_execution_backlog.py`.
- **Generated index:** [`INDEX.md`](INDEX.md) — regenerate with `python scripts/execution_doc_index.py`.

Day-by-day historical diaries were removed; new product behavior belongs in Tier 1 docs (`docs/ENGINEERING_ARCHITECTURE.md`, CHANGELOG) or Docusaurus.
