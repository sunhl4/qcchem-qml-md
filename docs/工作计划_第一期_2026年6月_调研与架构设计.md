# 量子计算化学软件平台 — 第一期工作计划（2026 年 6 月）

**本期范围** **行业与竞品调研**、**产品架构设计**。

## 工作块 A：行业调研与竞品分析

### 交付物

一份 **《量子计算化学软件平台 — 行业与竞品调研报告》**（Markdown + 可导出 PDF），提交至项目文档库。

### 指标

1. **调研说明文档（必须章节）**

   - 概述（市场背景、用户画像、本期结论摘要）
   - 需求与场景（药化/材料/教学/云托管四类场景优先级）
   - 调研方法与信息源（官方文档、论文、开源仓库、公开 API）
   - 竞品总览与定位图（商业平台 / 开源工具包 / 云作业平台）
   - 能力对比（≥15 项能力维度，含图例：领先 / 追赶 / 类比 / 不做）
   - 差距与机会（详细的竞争方向和本工程定位）
   - 风险与假设（许可证、开源或闭源协议等、硬件等后端适配等）
   - 附录（引用链接、术语表等）
2. **竞品覆盖（代码与文档层面）**

   - 商业/生态：**Quantinuum Vendor platform**（三柱心智：化学规格 / 程序构造 / 执行分析）
   - 开源主线：**Tangelo**、**Qiskit Nature**、**PennyLane Chemistry**、**OpenFermion等**
   - 后端与编译：**pytket/TKET**、**Qiskit**、**Braket / IonQ** 适配模式（归纳 adapter 模式，非逐家实现）
3. **可交付物质量**

   - 每个主要竞品 ≥1 页「定位 + 可借鉴 + 不照搬」结论
   - 能力对比中 **≥70%** 行有明确证据来源（文档章节 / 源码路径等）
   - 输出 **≥5 条** 可进入产品开发需求的条目

### 具体工作内容

1. **1.1 文献与产品文档采集**：整理各平台使用方式、许可证、默认依赖、教程入口 IA。
2. **1.2 能力维度拆解**：分子输入、嵌入/DMET、映射、ansatz、solver、protocol、mitigation、编译、后端、作业云、repro/Methods、MD/ML、CI 测试。
3. **1.4 用户场景及与公司云平台对接**讨论（≥2 场）：研发（算法）、应用（化学）、平台（作业/部署）等沟通纪要。
4. **1.5 调研报告评审**：组内或者组间交流，对调研方向的指导决策。

## 工作块 B：产品架构设计

### 交付物

一份 **《量子计算化学软件平台 — 产品架构设计说明书》**（Markdown + 架构图源文件）。

### 指标

1. **架构说明文档（可选章节）**

   - 概述（产品愿景、设计原则、与竞品差异一句话）
   - 需求规格（功能需求 FR / 非功能需求 NFR：可复现、可插件、多后端、自托管）
   - 设计思路（ 容器 / 组件；关键数据流）
   - 逻辑分层与模块边界（软件架构包的结构）
   - 核心契约（工程扩展和工作流的契约）
   - 扩展点（后续可持续扩展的模块和方向）
   - 部署视图（对接云平台的计划）
   - 文档与对外 IA（如有必要，则设计web端网站）
   - 安全与合规（数据和输出可审计，日志输出完善）
   - 其他
2. **架构设计产出**

   - **确定** 产品级 workflow graph（配置 → 经典 → 预量子 → 量子 → 协议 → 作业 → repro）
   - **确定** 插件 SPI 与版本策略（registry 注册、能力门）
   - **确定** 配置即契约：YAML 校验分层（`config_校验分层约定`）与 breaking change 策略
   - 架构评审通过：**≥2 名** 评审人（产品/架构/化学各 1）无阻塞意见
