# 量子计算化学软件平台 — 第二期工作计划（2026 年 7–8 月）

**本期范围**：**经典计算化学层集成交付**（代码 + 配置示例 + 教程脚本），拆为 **两个月、两册** 递进交付；承接第一期调研与架构设计，在量子算法阶段之前形成可回归、可审计的经典化学主线。

**前置依赖**：第一期《[行业与竞品调研报告](research/量子计算化学软件平台-行业与竞品调研报告.md)》与《[产品架构设计说明书](ENGINEERING_ARCHITECTURE.md)》已收口；`ChemIntegralSolver` 与 registry 骨架已落地；Phase A（`driver_meta`、benchmarks、active-space）在仓库中**已基本实现**，7 月以验收与文档化为主，8 月承接扩展路径。

**分期原则**：在**现有交付物**上分册——7 月不重复铺新后端，先把 PySCF 主路径与入门示例「可验收」；8 月再收 Psi4 / 嵌入 / precomputed，并完成说明文档定稿。

---

## 总览：两月分工

| 维度 | **7 月（上册）** | **8 月（下册）** |
|------|------------------|------------------|

| 评审 | 7 月底进度核对（可非正式） | **≥1** 场正式评审签字 |

### 指标

1. **代码（必须）**
   - Phase A DoD 四项确认（见 [`实施清单_PhaseA_PySCF继承改造.md`](实施清单_PhaseA_PySCF继承改造.md) §6）
   - `create_solver` → PySCF → `classical_mean_field_via_solver_bridge` → `PreQuantumInput` 无 orchestration 内硬编码
   - `run_classical_post_hf_benchmarks` 与 `driver_meta` 进入 parity 导出

2. **示例（必须）**
   - `configs/example_h2.yaml`（H₂ RHF → 下游 smoke）
   - `configs/example_h2_active_space_manual_strategy.yaml` 与 `example_h2_active_space_cas_strategy.yaml`（二选一或均保留为代表）

3. **文档（必须）**
   - 集成交付说明 v0.5：背景、workflow 经典段、五层子架构、**PySCF ≥1 页**对标
   - 能力表 **≥12 项**（分子 SCF、活性空间 manual/CAS、OpenFermion 桥、`driver_meta`、benchmarks 等），**≥70%** 有证据

4. **质量闸门**
   - `pytest tests/chem/test_pyscf* tests/chem/test_active_space* tests/chem/test_solver_registry_contract.py -q`
   - `python scripts/check_parity_export_sample.py`（抽样 **≥15** 份，以现有清单为基线）
   - `examples/run_all_smoke.py` 中 tutorial 01、04 可跑通

## 8 月：下册 — 多后端、嵌入与说明定稿

### 交付物

| 类别 | 路径 | 8 月要求 |
|------|------|----------|
| 核心代码 | Psi4、`precomputed`、`chem/embedding/*` | 次后端与嵌入代表路径 **可回归** |
| 配置示例 | `example_h2_psi4_*`、`example_h4_*`、`example_decomposition_plugin_*`、`example_h2_precomputed_bundle.yaml` 等 | 进阶 **≥5** 份写入文档索引 |
| 教程脚本 | 新增或更新 **≥1** 份经典化学专题 | 仅经典段或经典 + parity 导出 |
| 测试 | `test_cross_solver*`、embedding/plugin 相关 | 扩充并通过 |
| 文档 | 集成交付说明 | **v1.0** 全文章节 + PDF + 评审 |

### 指标

1. **代码（必须）**
   - `scf.driver=psi4` 代表路径经 registry 与 PySCF 共用 pre-quantum 契约
   - `precomputed` 双线路在说明文档中可审计描述
   - 嵌入择 **2 条**代表路径深化（DMET / Schmidt / plugin 中任选其二，以现有 `example_h4_*`、`example_decomposition_plugin_*` 为锚）

2. **示例（必须）**
   - 补全入门第 3 路径：`configs/example_h2_psi4_rhf_sto3g.yaml`
   - 进阶 **≥5** 份 YAML，覆盖嵌入 / AVAS / PBC / precomputed / plugin **至少 3 类**
   - 每个必交示例在 README 或 [`examples/测试与演示流程说明.md`](../examples/测试与演示流程说明.md) 有**一行用途**

3. **文档（必须）** — 工作块 A 全集成交付说明

   - **必须章节齐全**：概述、四类场景、方法与信息源、经典栈总览、能力对比 **≥15 项**、差距与机会、风险、附录
   - **经典栈覆盖**：PySCF、Psi4、Tangelo `IntegralSolver`、Vendor 化学规格柱、precomputed / plugin（归纳）
   - 每个主要后端 / 对照 **≥1 页**「定位 + 已接入 + 不宣称」
   - **≥5 条**可进入第三期开发需求
   - **PDF** 导出归档

4. **质量闸门**
   - `pytest tests/chem/ -q` 全绿
   - parity 抽样 **≥25** 份
   - 能力对比 **≥70%** 行有证据；文档与 `public_parity_matrix.md` 无冲突口径
   - 内部评审 **≥1** 场，无阻塞意见

### 8 月节奏（4 周）

| 周 | 任务 | 产出 |
|----|------|------|
| W1 | Psi4 + cross-solver；precomputed 文档化 | `example_h2_psi4_*` 纳入 parity 抽样 |

| W3 | 进阶 YAML 索引 + 经典专题 tutorial | 演示说明更新；`run_all_smoke` 全量 |
| W4 | 说明 v1.0、PDF、总闸、评审 | 第二期收口 |

- 不宣称 Quantinuum 闭源化学内核或 Nexus 等价
- 不将 ORCA / Gaussian 纳入数值主路径
