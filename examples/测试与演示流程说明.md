# 测试、脚本与输出目录说明

本文汇总本仓库内**自动化测试**、**示例脚本**、**烟测/工具脚本**及**建议输出路径**，便于复现实验与对照公开 parity 矩阵（`docs/public_parity_matrix.md`）。仓库根目录以下记为 `$ROOT`。

---

## 1. 单元与集成测试（pytest）

- **分子积分 / 开源对齐**：`tests/test_integral_openfermion_tangelo_recipe.py` 将本栈 PySCF→OpenFermion 路径与 **SandboxAQ Tangelo** 公开实现（`transpose(0,2,3,1)` + `InteractionOperator` 双体 ½）对齐；断言 H₂ CAS(2,2) 的 **扇区基态能量 = PySCF FCI**。若安装了 `tangelo`，同一文件中的可选用例会与 `SecondQuantizedMolecule` 的 JW 算符做数值对比（包在部分 Python 版本上可能无法从 PyPI 构建，可跳过）。

- **命令**（与 `CONTRIBUTING.md` 一致）：

  ```bash
  cd $ROOT
  pytest tests -q --tb=short
  ```

- **可选较慢用例**：`pytest -m slow tests/test_dmet_fragment_exact.py -q --tb=short`
- **CI 相关标记**：见 `pyproject.toml`；`CONTRIBUTING.md` 说明 PR 需覆盖 `-m l1_excited`、`-m l1_md_ml` 等。
- **缓存目录**：`.pytest_cache/`（已在 `.gitignore` 中）。

## 7. 「量子结果低于 SCF」的语义说明

- 在 **同一套活性空间分子哈密顿量** 上，PySCF→OpenFermion 的常数项与双电子积分缩放修正后，JW Hartree–Fock 参考态可与 `scf_energy` 对齐；此时 **变分能量低于 RHF** 表示在图上「下到 SCF 线以下」——教程 `tutorial_04` 与 `example_h2_uccsd.yaml` 即用于演示这一点。
- **UCCSD**：乘积 `expm` 链之后对 JW 计算基态做 **固定电子数子空间投影**（`jw_number_indices`），避免数值泄漏到错误粒子数扇区；测试中还断言变分能量 **不低于当前构建的 qubit 哈密顿量在该扇区上的最小本征值**（变分一致性）。与 **PySCF FCI** 的全谱对齐仍属积分/索引约定审计范围，见 `active_space_integrals` 文档说明。
- **Fe 可运行示例**：`configs/example_fe_sto3g_helike_rhf_cas22.yaml`（Fe 高离化 +24、2 电子、RHF、CAS(2,2)，HF 与哈密顿量参考态对齐）；**不等价**于中性 Fe / Fe4N2 教程占位链。
- 可复现入口：`examples/tutorial_04_uccsd_below_scf.py`、`configs/example_fe_sto3g_helike_rhf_cas22.yaml`，以及 `tests/test_orchestration_pipeline.py` 中对应用例。
